# gemma-2-2b

An unmodified copy of [`google/gemma-2-2b`](https://huggingface.co/google/gemma-2-2b),
the language model of the Base-SAE and FT-SAE detectors of *Building Auditable
AI Text Detectors with Sparse Autoencoders*, hosted so that those detectors
load without a gated download. Gemma is provided under and subject to the
Gemma Terms of Use found at https://ai.google.dev/gemma/terms, including its
use restrictions; see `NOTICE`.
